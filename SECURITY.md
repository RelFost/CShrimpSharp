# Security policy

## Supported versions

CShrimpSharp is currently in preview. Security fixes are applied to the latest preview release and the `main` branch.

| Version | Supported |
| --- | --- |
| Latest preview | Yes |
| Older previews | No |

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Use the repository's **Security → Report a vulnerability** flow to create a private GitHub security advisory for `RelFost/CShrimpSharp`. Include:

- the affected version or commit;
- a minimal reproduction;
- the security impact;
- whether cancellation, rollback, exception handling, or resource lifetime is involved;
- any proposed mitigation.

A report will be acknowledged through the private advisory. Public disclosure should wait until a fix or mitigation is available.
