# Архитектура и гарантии

CShrimpSharp намеренно остаётся небольшой библиотекой с минимумом зависимостей.

## Гарантии

- `Option<T>` намеренно не хранит null.
- `Result<TValue,TError>` должен быть явно инициализирован.
- `Map` и `Bind` сохраняют неактивную ветку.
- `SyncAsync` сохраняет порядок результатов.
- `SyncSettledAsync` сохраняет порядок входа и захватывает обычные исключения.
- `RaceAsync` наблюдает дочерние задачи перед возвратом.
- компенсации транзакции выполняются в LIFO-порядке.
- освобождение активной транзакции запускает rollback.

## Не является целью

- совместимость с исходным кодом Verse;
- собственный scheduler или actor runtime;
- распределённая атомарность;
- замена исключений для ошибок программирования и отмены.
