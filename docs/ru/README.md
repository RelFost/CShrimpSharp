## Рекомендуемый порядок чтения

**Разработчик приложения:** Начало работы → Основные типы → Асинхронная композиция → Практические рецепты.

**Код с большим количеством конкурентных операций:** Начало работы → Структурированная конкурентность → Архитектура и гарантии.

**Контрибьютор библиотеки:** Архитектура и гарантии → Выпуск версии → План развития.
